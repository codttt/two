# Техническое задание

## Назначение

Программа обрабатывает квадратную вещественную матрицу и формирует два
результата: обмен элементов главной и побочной диагоналей по строкам и по
столбцам.

## Входные данные

- положительное целое число `n`;
- `n` строк по `n` вещественных чисел.

Десятичным разделителем может быть точка или запятая.

## Выходные данные

Исходная матрица и две матрицы после выполнения преобразований.

## Требования

- ошибочный размер или строка должны запрашиваться повторно;
- исходная матрица не должна изменяться;
- дополнительные библиотеки для запуска программы не требуются.
