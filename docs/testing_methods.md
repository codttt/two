# Сравнение методов тестирования

| Метод | Что проверяет | Преимущество | Ограничение | Применение в проекте |
| --- | --- | --- | --- | --- |
| Эквивалентное разбиение | Классы корректных и ошибочных данных | Сокращает число однотипных тестов | Может пропустить ошибку внутри класса | Числа, текст, `bool`, пустая матрица |
| Граничные значения | Данные около границ | Находит ошибки в сравнениях и размерах | Не описывает взаимодействие условий | Размер 1, пустой ввод, нулевой и отрицательный таймаут |
| Покрытие решений | Истинный и ложный исход ветвлений | Показывает непройденные ветви | Не гарантирует отдельную проверку каждого условия | Статусы `ok`, `error` и неверный статус |
| Покрытие условий | Каждое логическое условие отдельно | Точнее покрытия решений | Не проверяет все сочетания | Тип, форма, длина и конечность матрицы |
| Комбинаторное покрытие | Сочетания логических условий | Выявляет ошибки взаимодействия условий | Число комбинаций быстро растёт | Основной метод варианта 14 |

Для проекта основным методом остаётся комбинаторное покрытие условий. Для размеров
матрицы и таймаутов его дополняют граничные значения, а для форматов ввода -
эквивалентные классы.
