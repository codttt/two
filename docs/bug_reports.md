# Баг-репорты

## BR-01 Неконечные числа принимаются при вводе

- Описание: `parse_row` принимал строки `nan`, `inf` и `-inf`.
- Шаги: вызвать `parse_row("nan", 1)`.
- Ожидаемое поведение: ввод отклоняется с `ValueError`.
- Фактическое поведение: возвращался список с неконечным значением.
- Тяжесть: высокая.
- Приоритет: высокий.
- Статус: исправлено, добавлен регрессионный тест.

## BR-02 Повреждённый JSON не создаёт ответ об ошибке

- Описание: `process_request_file` завершался исключением до формирования файла ответа.
- Шаги: записать `{broken` в `request.json` и вызвать `process_request_file`.
- Ожидаемое поведение: статус `error` и код `invalid_message` в файле ответа.
- Фактическое поведение: исключение `InvalidMessageError`, файл ответа отсутствовал.
- Тяжесть: средняя.
- Приоритет: высокий.
- Статус: исправлено, добавлен регрессионный тест.
