# Ревью тестов

Ревью выполнено после добавления комбинаторных и регрессионных проверок.

Проверено:

- у каждого теста есть одно наблюдаемое условие;
- тесты не зависят от порядка запуска;
- временные файлы создаются в `TemporaryDirectory`;
- в тестах есть корректные и ошибочные наборы;
- проверки воспроизводимы в Python 3.11, 3.13 и 3.14;
- два исправленных дефекта закрыты отдельным классом `RegressionTests`.

Замечание ревью: проверка неконечных чисел и повреждённого JSON должна оставаться
в регрессионном наборе. Замечание выполнено.
