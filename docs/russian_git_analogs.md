# Российские аналоги GitHub

## GitFlic

GitFlic поддерживает Git-репозитории, задачи, запросы на слияние и средства
непрерывной интеграции. Сервис подходит для хранения учебных и рабочих
проектов на российской платформе.

## GitVerse

GitVerse предоставляет репозитории, управление доступом, задачи и совместную
разработку. Интерфейс и основные операции близки к другим Git-платформам.

## Сравнение

GitHub выбран для лабораторной работы из-за прямого требования использовать
GitHub Actions, Pull Request и шаблоны GitHub. Исходный код не зависит от
платформы и может быть перенесен в другой Git-сервис обычными командами Git.
