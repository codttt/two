## Плотность дефектов

В `src/` находятся 315 непустых строк, не считая строки, которые начинаются с `#`.
Во время работы найдено два дефекта.

```text
2 / 315 x 1000 = 6,35 дефекта на 1000 строк
```

Оба дефекта исправлены. После повторного запуска плотность известных активных дефектов
равна нулю.

## Время обнаружения

Первый целевой запуск 11 тестов длился 0,013 с и воспроизвёл оба дефекта. Для этого
запуска среднее машинное время обнаружения составило 0,0065 с на дефект. Метрика
не включает время на подготовку тестов.
