# Архитектура программы

Программа разделена на небольшие функции.

- `read_size` считывает положительный порядок матрицы;
- `parse_row` преобразует одну строку ввода в числа;
- `read_matrix` формирует квадратную матрицу;
- `validate_square_matrix` проверяет форму данных;
- `swap_diagonals_by_rows` выполняет обмен внутри строк;
- `swap_diagonals_by_columns` выполняет обмен внутри столбцов;
- `print_matrix` выводит результат;
- `main` управляет последовательностью действий.

Обе функции преобразования создают копию матрицы. Поэтому один результат не
влияет на другой, а исходные данные сохраняются.

Для матрицы порядка `n` каждая функция выполняет `n` обменов. Временная
сложность самого преобразования равна `O(n)`. Копирование матрицы требует
`O(n^2)` памяти.
