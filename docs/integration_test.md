# Тестирование интеграции

## Цель

Проверить взаимодействие модулей, корректность JSON-контракта и обработку
ошибок на границах интеграционной системы.

## Тестовые сценарии

| № | Сценарий | Ожидаемый результат |
|---:|---|---|
| 1 | Полный обмен запросом и ответом через временные JSON-файлы | Получены оба правильных результата |
| 2 | Метод `rows` | В ответе присутствует только `results.rows` |
| 3 | Метод `columns` | В ответе присутствует только `results.columns` |
| 4 | Матрица нечетного порядка | Центральный элемент не изменен |
| 5 | Матрица 1 на 1 | Единственный элемент сохранен |
| 6 | Прямоугольная матрица | Ответ со статусом `error` |
| 7 | Отсутствующий файл | Ошибка `module_unavailable` |
| 8 | Файл не появился за установленное время | Ошибка `timeout` |
| 9 | Файл появился до истечения времени | Запрос успешно прочитан |
| 10 | Поврежденный JSON | Ошибка `invalid_message` |
| 11 | Версия схемы 2.0 | Ошибка `version_conflict` |
| 12 | Нечисловое или бесконечное значение | Данные отклонены |

## Команды проверки

```bash
python -m unittest discover -v
coverage run -m unittest discover -v
coverage report --fail-under=90
flake8 src tests tools
```
