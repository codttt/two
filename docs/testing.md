# Тестирование проекта

## План

Цель проверки - подтвердить обмен элементов главной и побочной
диагоналей, проверку входных данных и обмен JSON-сообщениями между
модулями. Проверяются все модули каталога `src/`.

Для варианта 14 используются `unittest` и комбинаторное покрытие условий.
Минимальное покрытие по заданию - 75 %. В CI установлен более строгий
порог 90 %.

## Метод варианта 14

В `tests/test_quality.py` сочетаются следующие условия:

- объект матрицы является списком и не пуст;
- каждая строка является списком нужной длины;
- элемент имеет числовой тип, не является `bool` и имеет конечное значение;
- запрос содержит версию, операцию, метод, идентификатор и матрицу;
- метод обработки равен `rows`, `columns` или `both`;
- ответ содержит один или оба результата.

Набор даёт положительные и отрицательные исходы для каждого существенного условия.

## Тестовые наборы

- `tests/test_main.py` - преобразование матрицы, граничные случаи и форматирование;
- `tests/test_integration.py` - JSON-обмен, таймауты, контракт и сквозные сценарии;
- `tests/test_quality.py` - комбинаторное покрытие, проверки модулей и регрессионные тесты.

## Протокол

| Группа | Входные данные | Ожидаемый результат | Фактический результат | Вердикт |
| --- | --- | --- | --- | --- |
| Обмен по строкам | Матрицы 1x1, 3x3 и 4x4 | Диагонали меняются в каждой строке | Результат совпал | Пройден |
| Обмен по столбцам | Матрицы 1x1, 3x3 и 4x4 | Диагонали меняются в каждом столбце | Результат совпал | Пройден |
| Проверка матрицы | Пустой список, неквадратная матрица, текст, `bool`, `nan`, `inf` | Данные отклоняются | Все наборы отклонены | Пройден |
| Метод обработки | `rows`, `columns`, `both`, неизвестное значение | Выполняются нужные ветви, ошибка отклоняется | Поведение совпало | Пройден |
| JSON-обмен | Корректный, повреждённый, запоздавший и отсутствующий файл | Ответ или контролируемая ошибка | Поведение совпало | Пройден |
| Вывод | Успешный ответ, ответ с ошибкой, неизвестный статус | Текст соответствует статусу | Все ветви проверены | Пройден |
