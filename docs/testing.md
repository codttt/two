# Тестирование

Автоматические тесты запускаются командой:

```bash
python -m unittest -v
```

Проверяются следующие случаи:

1. матрица порядка 4 и обмен по строкам;
2. матрица порядка 4 и обмен по столбцам;
3. сохранение центрального элемента матрицы нечетного порядка;
4. матрица из одного элемента;
5. сохранение исходной матрицы;
6. отклонение прямоугольной матрицы;
7. отклонение пустой матрицы;
8. ввод чисел с запятой;
9. проверка количества элементов в строке;
10. форматирование целых и дробных значений.

GitHub Actions повторяет проверку в Python 3.9, 3.10, 3.11, 3.12 и 3.13.
