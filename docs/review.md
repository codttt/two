# Ревью кода

## Проверенные свойства

- функции имеют одну понятную задачу;
- исходная матрица не изменяется;
- квадратная форма данных проверяется до обработки;
- центральный элемент матрицы нечетного порядка сохраняется;
- сообщения об ошибках объясняют причину повторного ввода;
- код не зависит от сторонних библиотек;
- критические ошибки Python контролируются flake8;
- основные и граничные случаи покрыты тестами.

Критических замечаний после проверки не осталось. Программа соответствует
