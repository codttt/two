# Обмен элементов главной и побочной диагоналей

Интегрированная система для варианта 14. Она вводит квадратную вещественную
матрицу и отдельно выполняет два преобразования:

1. меняет элементы главной и побочной диагоналей внутри каждой строки;
2. меняет элементы этих диагоналей внутри каждого столбца.

Исходная матрица сохраняется, поэтому оба результата вычисляются независимо.
В ЛР №3 программа разделена на модули, применяется восходящая стратегия, а
межмодульный обмен выполняется через версионированные JSON-файлы.

## Пример

Для матрицы порядка 3:

```text
1 2 3
4 5 6
7 8 9
```

обмен по строкам дает:

```text
3 2 1
4 5 6
9 8 7
```

обмен по столбцам дает:

```text
7 2 9
4 5 6
1 8 3
```

## Запуск

Требуется Python 3.9 или новее. Дополнительные библиотеки не нужны.

```bash
python src/main.py
```

Программа принимает точку или запятую в качестве десятичного разделителя.
Ошибочный размер и неправильная строка запрашиваются повторно.

Файловый режим интеграции:

```bash
python -m src.main \
  --request examples/request.json \
  --response examples/response.json \
  --timeout 1
```

Контракт сообщений и схема потоков данных описаны в
[`docs/integration.md`](docs/integration.md).

## Тесты

```bash
python -m unittest discover -v
coverage run -m unittest discover -v
coverage report --fail-under=90
flake8 src tests tools
```

В проекте подготовлено 35 модульных и интеграционных тестов. Отдельный workflow
проверяет код в Python 3.9, 3.11 и 3.13, запускает `flake8` и контролирует
покрытие не ниже 90 процентов.
